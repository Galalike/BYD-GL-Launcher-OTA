# BYD GL Launcher — OTA Releases

Official over-the-air (OTA) APK release distribution repository for **BYD GL Launcher** (BYD Atto 3 / DiLink 3.0).

- Check [Releases](https://github.com/Galalike/BYD-GL-Launcher-OTA/releases) for the latest signed APK builds.
- In-app updates check `releases/latest` automatically via **Settings → อัปเดตเวอร์ชัน (GitHub OTA)**.
